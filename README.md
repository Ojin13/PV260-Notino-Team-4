## Milestone 1 Feedback

- Create a separate branch for Milestone 1 (do not delete or merge it)
- Save ES & PM as .png files
- Remove email read model from process modeling

- Arrows – not recommended, because yes/no decisions can be visually unclear
- Swimlanes – do not use them as separators, they should go through the middle of the flow (move them behind each other)

- Policy – use a diamond shape for decisions; real policy has a different meaning (used for chaining events, e.g., event logged)
